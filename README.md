# Malco

An overlay tool for StarCraft: Brood War.
It uses bwrapi to read the game state and displays the overlay with the .NET 10 Windows Desktop Runtime.

## Features

- **Your forces at a glance**: See owned unit and building counts as icons, along with idle and total worker counts.
- **Resource gathering at a glance**: Check mineral workers at each base and assigned workers at each gas building directly on the map.
- **Research timing you will not miss**: See available upgrades, progress and time remaining, and completed items at each stage.
- **Command and rally paths**: Current and queued commands for selected units and rally points for production buildings are drawn as lines.
- **See inside every transport at a glance**: Check passenger types and counts above each loaded transport.
- **Spell readiness at a glance**: Display an energy value or ready indicator for each spellcasting unit and building.
- **Only what you need, where you want it**: Choose which features and items to show, then adjust icons, completion indicators, and HUD position and size.

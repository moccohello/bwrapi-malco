Malco Data Collection Terms

To understand feature usage and compatibility across versions, Malco sends the following information once each time it detects that a game has started:

- Malco application version
- Player race: Terran, Zerg, or Protoss
- Summary of current Malco settings
- A random installation identifier and a random game-session identifier

This data collection is required to install and use Malco and cannot be separately enabled or disabled in the application. If you do not agree, cancel the installation.
